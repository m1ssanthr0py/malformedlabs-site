# Malformed Labs

Source for the [Malformed Research](https://malformedlabs.net) website, hosted with GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or serve it locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This repo is published via GitHub Pages from the `main` branch root. Pushing to `main` updates the live site automatically.
